# Задание #1. Аналитика стримингового сервиса.

Функциональность реализована в модуле `catalog-analysis` с двумя точками входа:

```toml
[project.scripts]
catalog-analysis = "catalog_analysis:main"
demo = "catalog_analysis.demo.__main__:main"
```

*A)* Запуск на исполнение выходного отчета по каталогу фильмов:

```commandline
git checkout hw/catalog_analysis
uv sync
uv run catalog-analysis
```


*В)* Запуск скриптов, которые были указаны в отдельных заданий с целью демонстрации фукционала.
Для них сделано интерактивное меню запуска отдельных скриптов для каждого раздела.
Сами скрипты находятся в пакете `[demo]`.

```commandline
================ ДЕМО-МЕНЮ ================
  1. Разминка: переменные, числа, `math`
  2. Условия и `match`
  3. Циклы
  4. Строки
  5. Списки
  6. Словари
  7. Множества
  8. Итераторы и генераторы
  a. Запустить все по порядку
  q. Выход
============================================
Выберите пункт: 1
```

Для выполнения запуска необходимо ввести в консоли:
```commandline
uv run demo
```

*С)* Проект содержит набор `unit`-тестов для автоматизированного контроля качества кода:

```commandline
uv run pytest
```
