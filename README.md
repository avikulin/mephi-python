# yandex-mephi-python-basics


[МИФИ] Программирование на Python

Выполнение домашних заданий по курсу разработки на Python.

## Задание #1. Аналитика стримингового сервиса.

Cквозной мини-проект, объединяющий материал пройденных тем: от переменных и чисел до множеств, словарей, итераторов и генераторов. 
Представляет собой набор функций для внутреннего отчета стримингового сервиса, которые анализируют каталог фильмов — считают статистику, категоризируют записи, строят отчеты по жанрам и актерам, ищут топовые позиции.

> Рабочая ветка: [hw/catalog_analysis](https://github.com/avikulin/mephi-python/blob/hw/catalog_analysis/src/python_basics/dz-catalog-analysis-vikulin-m25-555/README.md)


## Задание #2. Примитивная база данных.

Мини-проект, который реализует упрощенный функционал базы данных:

- Создание / проверку и удаление таблиц, определять их структуру с типами данных;
- Сохранение метаданные таблиц в `JSON`-файл для персистентности;
- Полный набор `CRUD`-операций _(сreate / read / update / delete)_.

> Рабочая ветка: `hw/simple_db` (будет создана позже)


## Дополнительно

 - Общая схема построения - многомодульный проект `UV`.

 - Каждый модуль ведется в отдельной ветке и по мере готовности заливется в `main`.
